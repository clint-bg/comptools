HW08: Solve Equations

Systems of equations are solved by finding variable values that satisfy all of the equations. With linear systems of equations, there is typically a unique solution that is easy to solve, even for large-scale systems. Nonlinear equations can be more challenging to solve and may have multiple solutions. Variable bounds and a good initial guess are sometimes required for nonlinear systems of equations. This section is to solve systems of:

  • Linear systems of equations

  • Nonlinear systems of equations

Problem #1¶

Solve the following systems of linear algebraic equations (A x=b)\left(A\,x = b\right)(Ax=b) using matrix calculations such as:

[121.5−1][x0x1]=[00.5]\left[ {\begin{array}{cc} 1 & 2 \\ 1.5 & -1 \\ \end{array} } \right] \left[ {\begin{array}{c} x_0 \\ x_1 \end{array} } \right] = \left[ {\begin{array}{c} 0 \\ 0.5 \end{array} } \right][11.5​2−1​][x0​x1​​]=[00.5​]

An array is defined with square brackets as a list or numpy array.

Vector: A vector (1D array) is:

b=[00.5]b = \left[ {\begin{array}{c} 0 \\ 0.5 \end{array} } \right]b=[00.5​]

and is defined as a list:

b = [0,0.5]

or as a numpy array:

b = np.array([0,0.5])

Matrix: A matrix (2D array) is:

A=[121.5−1]A = \left[ {\begin{array}{cc} 1 & 2 \\ 1.5 & -1 \\ \end{array} } \right]A=[11.5​2−1​]

and is defined as a list:

A = [[1.0, 2.0],[1.5,-1.0]]

or as a numpy array:

A = np.array([[1.0, 2.0],[1.5,-1.0]])

Solution Method #1: The solution to this set of equations can be found by inverting the matrix AAA and multiplying by bbb as x=A−1 bx=A^{-1}\,bx=A−1b.

[x0x1]=[121.5−1]−1[00.5]\left[ {\begin{array}{c} x_0 \\ x_1 \end{array} } \right] = \left[ {\begin{array}{cc} 1 & 2 \\ 1.5 & -1 \\ \end{array} } \right]^{-1} \left[ {\begin{array}{c} 0 \\ 0.5 \end{array} } \right][x0​x1​​]=[11.5​2−1​]−1[00.5​]

The inverse of a matrix can be found with the function np.linalg.inv. Two matrices are multiplied together with the dot product with function np.dot.

# practice problem
import numpy as np
A = [[1.0, 2.0],[1.5,-1.0]]
b = [0,0.5]
invA = np.linalg.inv(A)
x = np.dot(invA,b)
print(x)

x = np.linalg.solve(A,b)
print(x)

Problem #2¶

A nonlinear equation solver such as scipy.optimize.fsolve can also solve linear equations. Returning to the introductory example:

[121.5−1][x0x1]=[00.5]\left[ {\begin{array}{cc} 1 & 2 \\ 1.5 & -1 \\ \end{array} } \right] \left[ {\begin{array}{c} x_0 \\ x_1 \end{array} } \right] = \left[ {\begin{array}{c} 0 \\ 0.5 \end{array} } \right][11.5​2−1​][x0​x1​​]=[00.5​]

This is solved with fsolve by placing all of the equations to one side as:

[121.5−1][x0x1]−[00.5]=[f0f1]\left[ {\begin{array}{cc} 1 & 2 \\ 1.5 & -1 \\ \end{array} } \right] \left[ {\begin{array}{c} x_0 \\ x_1 \end{array} } \right] - \left[ {\begin{array}{c} 0 \\ 0.5 \end{array} } \right] = \left[ {\begin{array}{c} f_0 \\ f_1 \end{array} } \right][11.5​2−1​][x0​x1​​]−[00.5​]=[f0​f1​​]

The equation is solved when f0f_0f0​ and f1f_1f1​ are equal to zero. The fsolve function requires a function that returns the residuals (f1f_1f1​ and f2f_2f2​).

#notice the use of the array or list to specify x0 and x1 (other variables may be specified like x and y in the equations as
#variables and you'd still use the array of x[:] or you could use a tuple)
def f(x):
    f1 = x[0]+2*x[1]
    f2 = 1.5*x[0]-x[1]-0.5
    return [f1,f2]

The function solver fsolve also needs an initial guess. A few guess values are evaluated below.

# values of the function at a few points (guesses)
print(f([0.0,0.0]))
print(f([0.5,0.5]))
print(f([1.0,0.0]))
[0.0, -0.5]
[1.5, -0.25]
[1.0, 1.0]

Guess values for x0x_0x0​ and x1x_1x1​ are selected as [1,1] and fsolve finds the solution.

from scipy.optimize import fsolve
x = fsolve(f,[1,1])
print(x)
[ 0.25  -0.125]

    return (f1,f2)

Problem #4¶

Imagine mixing liquid benzene (species 1) and toluene (species 2) together in an initially empty container. At equilibrium, some of the liquid from both species evaporates into the vapor phase and some is left liquid phase for certain temperatures and pressures. In thermodynamics, you learn that Raoult’s law may be used to describe the distribution of species in each phase. For the specific example mentioned above, Raoult’s law gives the following two expressions describing the equilibrium state

y1P=x1P1sat(T)y2P=x2P2sat(T)\begin{align} y_1 P = x_1 P_1^{sat}(T) \\ y_2 P = x_2 P_2^{sat}(T) \end{align}y1​P=x1​P1sat​(T)y2​P=x2​P2sat​(T)​​
(1)

where yiy_iyi​ is the mole fraction of species iii (either 1 or 2) in the vapor phase, xix_ixi​ is the mole fraction of species iii in the liquid phase, Pisat(T)P_i^{sat}(T)Pisat​(T) is the vapor pressure of species iii at the system temperature TTT, and PPP is the system pressure.

The vapor pressures of benzene and toluene can be found using the Antione Equation given below:

ln⁡(Pisat(T))=Ai−BiT+Ci\ln{\left(P_i^{sat}(T) \right)} = A_i - \frac{B_i}{T+ C_i}ln(Pisat​(T))=Ai​−T+Ci​Bi​​
(2)

Note that Pisat(T)P_i^{sat}(T)Pisat​(T) is not PisatP_i^{sat}Pisat​ times TTT, but is simply showing that PisatP_i^{sat}Pisat​ is a function of TTT in kPa. The constants, AAA, BBB, and CCC, are compound specific and are found in the table below. TTT is in °C°C°C in the above equation.
